# Фотоархив

`cloudphoto` — консольная программа для управления фотоальбомами в Yandex Object Storage. Фотографии и страницы статического сайта хранятся в одном бакете.

Программа поддерживает просмотр альбомов, загрузку, скачивание и удаление фотографий, а также публикацию сайта командой `mksite`.

Для сборки нужен Go. Сдаваемая сборка предназначена для Linux x86_64. Инфраструктура описывается в директории `terraform`; для неё нужен Terraform и настроенный профиль Yandex Cloud CLI.
